# ADR Título: ADR-002 – Aplicação de Domain Driven Design (DDD)

- **Status:** Aprovado (6 de junho de 2026)
- **Data:** 2026-06-06
- **Autores:** Elir de Assis Ribeiro

## Contexto

O domínio principal da aplicação é o gerenciamento de produtos.

As regras de negócio devem permanecer independentes da infraestrutura.

## Decisão

- Centralizar o modelo de domínio na camada Domain.

A camada contém:

Entidades
Interfaces de repositório
Exceções de domínio

## Consequências:

## Benefícios

Regras de negócio isoladas
Facilidade de evolução
Independência tecnológica

## Trade-offs:

Exige disciplina para evitar vazamento de infraestrutura
