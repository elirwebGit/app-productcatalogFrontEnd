# ADR Título: ADR-004 – Repository Pattern

- **Status:** Aprovado (6 de junho de 2026)
- **Data:** 2026-06-06
- **Autores:** Elir de Assis Ribeiro

## Contexto

O domínio não deve conhecer detalhes de persistência.

## Decisão

Criar abstrações através de interfaces na camada Domain.

Exemplo:

IProductRepository

As implementações ficam na camada Infrastructure.

## Consequências:

## Benefícios

Baixo acoplamento
Facilidade para mocks em testes
Independência do banco de dados

## Trade-offs:

Necessidade de manter abstração e implementação
