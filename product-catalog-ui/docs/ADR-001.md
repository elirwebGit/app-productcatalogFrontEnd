# ADR Título: ADR-001 – Utilização de Clean Architecture

- **Status:** Aprovado (6 de junho de 2026)
- **Data:** 2026-06-06
- **Autores:** Elir de Assis Ribeiro

## Contexto

A aplicação possui regras de negócio, acesso a dados e exposição de endpoints HTTP.

Uma estrutura monolítica tradicional poderia gerar forte acoplamento entre as camadas, dificultando manutenção e testes.

## Decisões Drivers (Requisitos)

- Adotar Clean Architecture dividindo a solução nas seguintes camadas:

Domain
Application
Infrastructure
Presenter/API

## Consequências:

## Benefícios

Baixo acoplamento
Alta coesão
Facilidade de manutenção
Facilidade para testes unitários
Independência da infraestrutura

## Trade-offs:

Maior número de projetos
Curva de aprendizado inicial maior
Mais código de configuração
